# Examples

Run an example by feeding it to the shell:

```bash
./greaterbash < examples/basics.sh
```

| File           | Shows                                      |
|----------------|--------------------------------------------|
| `basics.sh`    | pipes, redirections, `&&`, `\|\|`, groups  |
| `math.sh`      | arithmetic expansion `$(( ))`              |
| `variables.sh` | variables, quoting, `$?`, `$$`             |
| `jobs.sh`      | background jobs                            |
